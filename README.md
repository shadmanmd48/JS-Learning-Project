# 🎮 JavaScript Learning Projects

A collection of beginner-friendly JavaScript mini-projects built to practice DOM manipulation, event handling, and core JavaScript concepts.

---

## 🎯 Project: Number Guessing Game (`Mini learning project3`)

An interactive web-based game where the player tries to guess a randomly generated number between **1 and 100** within **10 attempts**.

### ✨ Features
- 🎲 **Random Number Generation**: Generates a new random target between 1 and 100 each game.
- 🔢 **Guess Validation**: Prevents invalid inputs (empty, letters, numbers < 1 or > 100).
- 📜 **Guess History**: Displays all previous guesses so you don't repeat them.
- ⏳ **Remaining Attempts**: Real-time counter showing how many of the 10 tries are left.
- 💡 **Helpful Hints**: Tells you whether your guess was too **High** or too **Low**.
- 🔄 **Play Again**: Instant restart button when the game ends or when you win.

---

### 🛠️ Built With
- **HTML5** – Game structure
- **CSS3** – Clean dark-themed styling
- **JavaScript (Vanilla)** – Game logic and DOM manipulation
